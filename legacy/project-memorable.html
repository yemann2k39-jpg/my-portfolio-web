Memorable | Discover the Unseen

Full-Stack Web Geospatial Data Community Platform

A map-first community platform designed to surface authentic experiences and filter out digital noise, free from influencer hype.

Visit Live Project

The Problem

Modern travel discovery is broken. Algorithms prioritize engagement over authenticity, flooding users with influencer hype and overcrowded tourist traps. Authentic, quiet, and culturally rich locations are buried. Furthermore, existing platforms suffer from duplicate content and karma-farming, making it impossible to verify if a location is genuinely worth visiting.

The Solution

Memorable is a map-first platform engineered to surface authentic experiences. By anchoring the user experience to a map rather than an infinite scroll, and by implementing technical safeguards against duplicate content, Memorable fosters a community built on genuine, verified exploration.

Key Features

Map-First Architecture

The main interface is an interactive map. All exploration and posting originate from the map. Users can search by location name or filter by "vibes" and categories (e.g., "Cozy," "Hidden Gem"), with pins dynamically rendered based on the viewport.

Geospatial Deduplication

To maintain data integrity, I implemented a radius-based deduplication algorithm. When a user attempts to post a new spot, the system queries existing posts within a 1km radius. If a similar name or tag exists, it prompts the user to add a review/comment to the existing post instead, while still allowing an override if necessary.

Community Validation System

Trust is built through a unique review system. Users who have visited the same place post under the original story. They rate the location on Authenticity, Crowd Level, and Value (1-10). This crowdsourced verification ensures the post remains honest and free from influencer bias.

Hyper-Local Discovery

A location-based suggestion engine highlights hidden spots within a 10km radius of the user, encouraging the exploration of nearby unseen places. Users can also save spots to their profile for future trips.

Future Improvements

  • Offline Maps: Allowing users to download map areas and saved spots for exploration in areas with poor network coverage.
  • Social Graph Integration: Implementing a trust score based on social connections, allowing users to weight reviews higher if they come from people within their extended network.
