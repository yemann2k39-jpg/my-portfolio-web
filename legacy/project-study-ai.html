Study AI Assistant

Mobile App AI / LLM UI/UX

Unifying document viewing and AI interaction into a single, dynamic study session to eliminate context-switching.

The Problem

Students often switch between PDFs, AI chatbots, and note-taking apps while studying. On mobile devices, this becomes even more disruptive due to constant tab switching and scattered resources, making revision less focused and inefficient.

The Solution

Study AI Assistant is a mobile application that bridges the gap between reading and querying. Users upload PDFs, create dedicated study spaces, and chat with an AI that understands the context of their materials, all within a single screen. Integrated note-taking ensures all insights are captured in one place.

Key Features

Dynamic Split-Screen UI

The interface splits the screen between a PDF viewer and a chat window. Recognizing that user focus shifts during study, both panels are expandable—allowing a user to maximize the PDF while reading, or expand the chat when deep in a Q&A session.

Contextual AI Chat

Users can select single or multiple uploaded PDFs to bind to a study session. The AI processes the context of these specific documents, ensuring answers are accurate and relevant to the material being studied.

Session-Bound Note-Taking

A native note-taking feature allows users to jot down insights without leaving the app. All data—chat history, PDF states, and user notes—are bound uniquely to each study session, creating a comprehensive, revisit-able study log.

Future Improvements

  • Automated Flashcard Generation: Integrating LLM capabilities to parse PDF sections and generate spaced-repetition flashcards automatically.
  • Note Summarization: Implementing an AI agent to condense multi-page session notes into concise, digestible summaries for exam revision.
